축제의 빈자리 — 생성 완료 이미지 사용 안내

제작일: 2026-11-01
실제 제작 도구: OpenAI built-in imagegen. Google Imagen 제작물이 아니다.
앱 코드는 작성하지 않았으며, 아래 PNG 18장과 사용 안내만 제공한다.
모든 이미지는 생성 후 시각 확인했고 파일을 열어 크기를 확인했다. 배지 3장의 PNG 알파 채널과 투명한 모서리를 확인했다. 별도 크롭·색 보정·압축 편집은 하지 않았다.

폴더
images/ : 생성 원본을 파일명별로 복사한 PNG 18장
ASSET_MANIFEST.json : 실제 생성 프롬프트와 참조 이미지, 도구 기록. 공모전 AI 활용 내역 작성에 사용.
IMAGE_CHECKS.json : 각 파일의 실제 크기·픽셀 형식·모서리 알파·용량 확인.

1. 인트로와 엔딩 — 각각 한 장의 이미지가 화면의 기본 구성

intro-desktop.png / 1672×941
용도: 데스크톱 첫 화면.
대체 텍스트: 학교 축제의 체험권과 자료를 살펴보며 함께 이야기하는 네 학생.
제목·부제·입장 버튼은 왼쪽 약 35%의 어두운 영역 위에 HTML로 배치한다. 이미지를 늘려 찌그러뜨리지 않는다.

intro-mobile.png / 941×1672
용도: 모바일 첫 화면.
대체 텍스트: 축제 조명 아래 공동 계획을 세우는 네 학생과 체험권 상자.
상단의 어두운 하늘에 제목, 하단의 어두운 영역에 입장 버튼을 배치한다. 중앙의 인물을 덮지 않는다. 데스크톱 이미지를 잘라 대신 사용하지 않는다.

ending-desktop.png / 1672×941
용도: 데스크톱 정리 화면.
대체 텍스트: 축제 공간의 큰 빈 게시판 옆에서 함께 토의하는 학생들.
왼쪽 빈 남색 게시판 안에 실제 학급의 결정·질문·성찰을 HTML로 배치한다. 게시판이 원근을 가지므로 글자는 게시판 안쪽의 충분히 좁은 안전 영역에 둔다. 오른쪽 인물과 하단 테이블을 가리지 않는다.

ending-mobile.png / 941×1672
용도: 모바일 정리 화면.
대체 텍스트: 커다란 빈 게시판 아래 모여 활동을 마무리하는 학생들.
상단~중앙 게시판 안에 실제 학급 결과를 표시한다. 긴 결과는 간결한 핵심 문장으로 줄이고 상세 내용은 접근 가능한 별도 영역에 둔다. 결과를 이미지에 미리 합성하지 않는다.

scene-redesign.png

세 장면은 왼쪽 어두운 영역을 질문 오버레이로 활용할 수 있다. 모바일에서는 전체 장면을 16:9 그림으로 먼저 보여주고 질문·선택지는 아래에 배치해 인물이 잘리지 않게 한다. 그림 속 티켓·인원·연결선 수를 실제 게임 데이터로 읽지 않는다. 실제 배정 결과와 수치는 HTML로 제공한다. 삽화는 비유적 장면이다.

5. 공동 진행 배지 — 모두 1254×1254, 실제 투명 배경 PNG

badge-perspective.png
대체 텍스트: 같은 크기의 세 렌즈가 겹친 관점 발견 배지.

badge-evidence.png
대체 텍스트: 자료 폴더와 돋보기로 표현한 근거 확인 배지.

badge-revision.png
대체 텍스트: 서로 맞물린 조각으로 표현한 규칙 수정 배지.

배지는 학급 전체의 활동 진행 표시다. 개인의 도덕성 점수나 순위에 사용하지 않는다. 화면에서는 적절히 축소해 사용하고 투명도를 유지한다. 장식 배지 옆에 동일 의미의 텍스트가 있으면 alt=""를 사용해 중복 낭독을 피한다.

구현할 때
- 원본 PNG를 보존하고, 실제 앱용 WebP/AVIF 최적화 파일은 별도로 만들어 대응표에 기록한다.
- 앱 공개 경로의 예: public/images/festival/*.png. 소스의 절대 컴퓨터 경로를 웹 URL로 쓰지 않는다.
- 첫 화면에 필요한 이미지만 우선 로드하고 나머지는 해당 장면 전후에 로드한다.
- 텍스트 대비, 키보드 접근성, 이미지 대체 텍스트, 작은 화면의 크롭을 실제 앱 구현 후 검증한다.
- 이 이미지들은 현재 생성된 시각 자료다. 멀티플레이 기능과 45분 수업 효과가 검증됐다는 의미는 아니다.
