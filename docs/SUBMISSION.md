## 1. 기획 의도

중학생에게 AI 윤리를 "용어 암기"나 "착한 선택 고르기"로 가르치면 남는 것이 적습니다. 이 작품은 학급 전체가 **하나의 배정위원회**가 되어, 가상의 축제 체험권 6자리를 신청자 12명에게 어떻게 배정할지 AI 추천을 두고 함께 결정하는 45분짜리 실시간 게임입니다.

학급이 고른 규칙으로 실제 배정이 계산되고, 그 결과를 보고 단서를 조사하고, 규칙을 다시 설계하면 **같은 12명에게 다른 결과**가 나옵니다. 흥미의 원천은 단서 발견, 예상과 다른 결과, 선택에 따른 분기, 여러 관점의 조합, 학급 공동 결정입니다. 결말은 "정답을 찾았다"가 아니라 "우리의 기준은 이렇게 달라졌다"와 "아직 풀지 못한 질문 하나"입니다.

다루는 윤리 원칙은 두 가지로 제한했습니다.
- **공정성·포용성** — 같은 규칙이어도 출발 조건이 다르면 불리해지는 사람이 생길 수 있음을 사례로 체험하고, 처음 참여하는 사람의 기회와 여러 입장의 참여를 규칙에 반영해 봅니다.
- **투명성** — AI가 어떤 기준으로 계산했는지, 동점은 어떻게 정했는지, 떨어진 사람이 무엇을 들었는지를 조사하고, "기준을 공개해도 자리는 바뀌지 않는" 경우를 직접 봅니다.

앱의 AI는 외부 생성형 AI API 없이 정해진 식을 계산하는 교육용 시뮬레이터이며, 첫 화면·도움말·교사 자료에 "실제 사람을 평가하지 않는 가상 AI 배정 실험"임과 실제 AI는 더 복잡하다는 점을 표시합니다.

## 2. 대상 학년과 운영 조건

- 중학교 1~3학년, 한 학급 24~36명(최대 학생 40명 + 교사 + 공개 화면).
- 교사 1명 진행, 45분 1차시. 느린 학급용 35분 단축안 제공(`TEACHER_GUIDE.md` §3).
- 기기: 학생 1인 1기기(휴대폰·태블릿·노트북, 360px 폭부터), 교사 노트북, 프로젝터용 공개 화면. 인터넷 연결 필요. 음향은 선택.
- 학생 개인정보: 본명·학번·이메일·학교·전화번호를 입력받지 않음. 서버가 가명을 발급하고, 방 데이터는 교사 즉시 삭제 또는 24시간 자동 삭제.

## 3. 교육 활용방법

| 시간 | 활동 | 학생이 하는 것 |
|---|---|---|
| 0~7분 | 입장·인트로·연습·사전 판단 | 가명 입장, 한 장의 키아트로 문제 파악, 제출·공개 방식 연습, "같은 규칙이면 늘 공정할까?" 개인 기록 |
| 7~15분 | 라운드 1 첫 배정 | 선착순/경험 우선/첫 참여 우선 비밀 투표 → 학급 선택으로 6명 배정 → 누가 남았는지 관찰 → 더 알고 싶은 정보 선택 |
| 15~25분 | 라운드 2 설명되지 않은 빈자리 | 무작위 관점 카드(신청자/처음 참가자/운영자/안내 담당자)로 조사 카드 2장 선택·의견 태그·80자 이유 → 단서 공개·인물 반응·관점 보드·기본 자료 |
| 25~35분 | 라운드 3 규칙 다시 설계 | 배정 기준·설명 방식·이의 제기를 묶은 패키지 4개 중 투표 → 같은 데이터로 재배정 → 이전·이후 비교, 유리/불리해진 사람, 남은 문제 |
| 35~40분 | 공동 약속·다른 상황 | "AI 결정을 받으면 먼저 물어볼 질문" 2개 투표, 동아리 체험 자리 사례에 적용 |
| 40~45분 | 성찰·엔딩 | 사전 문항 재응답과 이유, 엔딩 이미지 위에 학급의 규칙·질문 2개·남은 질문 1개를 실제 데이터로 표시, 교사용 익명 요약 |

**작품의 중심은 웹앱 내부의 인터랙티브 경험**입니다. 교사 가이드와 활동지는 보조 자료이며, 프로그램(② 부문) 형태의 교안이 아니라 앱 안에서 학급의 선택이 결과를 바꾸는 체험이 본체입니다.

## 6. 생성형 AI 활용 범위 (요약)

이미지 18장은 OpenAI built-in imagegen으로 사전 생성한 원본 PNG를 WebP로 최적화해 사용했고, 배경음악 3곡·효과음 7개는 ElevenLabs로 제작된 파일을 받아 사용했습니다. 앱 코드·콘텐츠 데이터·문서는 Claude Code(Claude)로 작성했습니다. 앱 런타임에는 생성형 AI API를 사용하지 않습니다. 상세 내역은 `AI_USAGE.md`와 `assets/ASSET_MANIFEST.json`에 있습니다.
