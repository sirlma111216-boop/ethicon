> 이 문서의 "검증됨"은 자동 테스트·시뮬레이션 결과를 뜻합니다. 실제 학급 수업 실증은 아직 하지 않았으며 해당 항목은 "미검증"으로 표기했습니다. 수상이나 점수를 보장하는 표현은 쓰지 않습니다.

## 1. 기획 의도

중학생에게 AI 윤리를 용어 암기나 "착한 선택 고르기"로 가르치면 남는 것이 적습니다. 이 작품은 **AI를 화면 속 등장인물로 세우고**, 학급 전체가 그 추천을 심사하는 **배정위원회**가 되어 45분 동안 **여섯 번 결정**하는 실시간 게임입니다.

- **AI가 보입니다.** "AI 배정기"는 어떤 자료 3가지를 봤는지, 어떤 기준(신청 시각 순)으로 6명을 추천했는지, 무엇을 설명하고 무엇을 "확인하지 않은 것: ???"으로 남겼는지 출력문으로 보여 줍니다. 학생은 AI의 결과가 아니라 AI의 **판단 과정**을 심사합니다.
- **선택이 다음 장면을 바꿉니다.** 결정 2에서 추천을 확인 없이 승인하면 다음 날 이의 제기 편지 세 통이 오고 조사 토큰이 1개로 줄어듭니다. 보류하면 운영자가 기다리는 대신 토큰 2개를 얻습니다. 결정 4에서 고른 묶음에 따라 AI가 같은 12명을 다시 계산해 유리해진 사람과 새로 불리해진 사람이 달라지고, "기준 공개" 묶음을 고르면 설명은 늘지만 자리는 바뀌지 않는 것을 직접 봅니다.
- **결정은 여섯 번뿐, 한 번에 한 탭입니다.** 설문처럼 느껴지지 않도록 각 결정의 결과가 화면에 돌아오고, 학생 화면 맨 위에 "할 일" 한 줄이 무엇을 몇 개 골라야 하는지 적혀 있습니다.
- **원칙은 두 개로 제한했습니다.** 공정성·포용성(같은 규칙이라도 출발선이 다르면 불리해지는 사람이 생김)과 투명성(AI가 쓴 자료·기준·한계를 알 수 있고 이의를 말할 수 있음). 엔딩에서 학급이 한 일을 이 두 원칙의 이름과 공식 원문 요지에 연결합니다.

앱 속 AI는 외부 생성형 AI API 없이 정해진 식을 계산하는 교육용 시뮬레이터이며, 첫 화면·인트로·엔딩·교사 자료에 그 사실과 "실제 AI는 더 복잡하다"는 안내를 표시합니다. 작품의 중심은 **웹앱 안의 인터랙티브 경험**이며, 교사 가이드와 활동지는 보조 자료입니다.

## 2. 대상 학년과 운영 조건

- 중학교 1~3학년, 한 학급 24~36명(최대 학생 40명 + 교사 + 공개 화면). 교사 1명 진행, 45분 1차시. 35분 단축안 제공(TEACHER_GUIDE.md §3).
- 기기: 학생 1인 1기기(휴대폰·태블릿·노트북), 교사 노트북, 프로젝터용 공개 화면. 인터넷 필요. 음향은 선택(한 화면에서만 출력).
- 개인정보: 본명·학번·이메일·학교·전화번호를 입력받지 않음. 서버가 가명 발급. 개인 선택·자유 응답은 교사 즉시 삭제 또는 24시간 자동 삭제. 자유 응답은 80자, 교사 승인 후에만 익명 공개. 3명 미만 집계는 묶음 처리.
- 교사 혼자 미리 돌려볼 수 있도록 연습용 봇 학생 기능과 "학생 화면 미리보기"를 교사 화면에 넣었습니다.

## 3. 교육 활용방법 (13장면 · 학생 결정 6번)

| 시간 | 장면 | 학생이 하는 것 | 결과로 보이는 것 |
|---|---|---|---|
| 0~3 | 입장 대기 | 코드·QR로 가명 입장 | 참여 안내 |
| 3~7 | 축제의 빈자리 | 이야기·신청자 12명·AI 배정기가 본 자료 3가지 읽기 | 키아트, AI 카드, 신청자 카드 |
| 7~8 | 결정 1 · 지금 내 생각 | "자료대로 계산하면 공정할까?" 1탭 | 응답 수만(분포 비공개) |
| 8~13 | 결정 2 · AI 추천을 어떻게 할까 | AI 출력문 읽고 승인/보류/거부 1탭 | 학급 분포, 결정 |
| 13~16 | 우리 결정의 결과 | 분기 장면 보기 | 편지 3통+토큰 1 / 조사 시작+토큰 2 / 운영자의 질문+토큰 2 |
| 16~22 | 결정 3 · 무엇부터 조사할까 | 관점 카드로 생각하며 카드 토큰 수만큼 + 한마디 1개 | 카드 투표 |
| 22~27 | 단서 공개 | 열린 카드·떨어진 사람의 말·관점 보드·기본 자료 보기 | "AI 배정기가 몰랐던 것" |
| 27~32 | 결정 4 · 규칙을 어떻게 바꿀까 | 네 묶음 중 1탭 | 학급 분포, 결정 |
| 32~36 | AI 배정기 다시 돌리기 | 이전/이후 비교, AI 설명문, 유리/불리, 남은 문제 보기 | 같은 12명의 다른 결과 |
| 36~40 | 결정 5 · 다른 AI에게 먼저 물어볼 것 | 동아리 사례에서 질문 1탭 → 상위 2개가 약속 | 공동 약속 2개 |
| 40~43 | 결정 6 · 다시, 내 생각 | 처음 질문에 1탭 + 이유(선택) | 개인 전후 비교(본인만) |
| 43~45 | 우리의 기준은 이렇게 달라졌다 | 엔딩 키아트 위 실제 학급 데이터, 원칙 카드 2장 | 교사 익명 요약 |

## 5. 검증된 것과 아직 하지 않은 것

## 6. 생성형 AI 활용 요약

이미지 18장은 OpenAI built-in imagegen(2026-11-01), 음향 10개는 ElevenLabs(Eleven Music / Sound Effects), 코드·문서 초안은 Anthropic Claude Code 로 제작했습니다. 앱 내부에는 생성형 AI API 를 쓰지 않습니다. 상세는 AI_USAGE.md.
