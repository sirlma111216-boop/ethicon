## 1. 완성 콘텐츠 접속

- **운영 주소:** https://ethicon.labbitory.com (심사 기간 내내 접속 가능, 회원가입 없음)
- **코드 원본:** https://github.com/sirlma111216-boop/ethicon (main 브랜치, 푸시 시 자동 배포)
- **형태:** 교사 1명 + 학생 최대 40명 + 교실 공개 화면(프로젝터)이 동시에 접속하는 실시간 협력 웹앱. 인터넷이 연결된 휴대폰·태블릿·노트북 브라우저에서 바로 실행되며 설치가 필요 없습니다.
- 첫 화면과 도움말에 "실제 사람을 평가하지 않는 가상 AI 배정 실험"임을 표시합니다. 앱 속 AI 배정기는 정해진 식을 계산하는 교육용 시뮬레이터이며 외부 생성형 AI를 호출하지 않습니다.

## 2. 심사위원이 혼자 체험하는 방법 (5분)

1. 운영 주소에서 **교사로 시작 — 방 만들기**를 누릅니다. 6자리 코드와 공개 화면 링크가 생깁니다.
2. 오른쪽 **연습용 봇 학생** 패널에서 **봇 25명 추가**를 누릅니다. 봇은 활동이 열릴 때마다 몇 초에 걸쳐 그럴듯한 답을 제출하는 가짜 학생입니다.
3. **수업 시작**을 누른 뒤 **다음 장면 →** 과 **결과 공개**만 번갈아 누르면 45분 흐름 전체를 몇 분 안에 볼 수 있습니다. 왼쪽 **학생 화면 · 지금 이렇게 보여요** 틀 안에 학생이 보는 화면이 그대로 표시됩니다.
4. 학생 화면을 직접 써 보려면 다른 기기(또는 시크릿 창)에서 **학생 입장**을 누르고 코드를 입력합니다. 본명·학번은 입력하지 않으며 서버가 가명을 발급합니다.
5. 결정 2에서 봇 대신 직접 "이대로 승인"을 고르면 다음 날 이의 제기 편지가 오고 조사 토큰이 1개로 줄어드는 분기를 볼 수 있습니다.

## 4. 학생의 선택이 결과를 바꾸는 구조

- AI 배정기의 첫 추천은 기본 설정(선착순)으로 고정되어 있고, **결정 2**에서 승인하면 조사 토큰이 1개, 보류·거부하면 2개가 됩니다. 토큰 수는 결정 3에서 열 수 있는 카드 수가 됩니다.
- **결정 4**의 네 묶음은 같은 12명에게 서로 다른 결과를 냅니다. "AI 추천 그대로"와 "그대로 + 기준 공개"는 자리가 같고 설명만 달라서, 설명 공개가 결정을 자동으로 공정하게 만들지 않음을 보여 줍니다. "신청 기회 보정 + 첫 참여 2자리"와 "첫 참여 3 + 경험자 3"은 자리가 바뀌며, 유리해진 사람과 새로 불리해진 사람을 함께 표시합니다.
- 엔딩의 "아직 풀지 못한 질문"은 고른 묶음과 새로 자리를 잃은 신청자 이름으로 만들어집니다.

## 5. 참여·익명성 설계

- 본명·학번·이메일을 입력받지 않고 서버가 가명을 발급합니다. 개인 선택은 교사에게도 분포로만 보이고, 3명 미만 항목은 묶어서 표시합니다.
- 자유 응답은 80자 이내이며 교사가 익명 원문을 승인한 것만 공개됩니다. 자유 채팅은 없습니다.
- 동률이면 30초 재투표, 다시 동률이면 교사가 이유를 남기고 결정하며 "교사 결정"으로 구분 표시됩니다. 기권·미응답은 분모와 함께 표시하고 동의로 세지 않습니다.
- 방 데이터는 교사가 즉시 삭제할 수 있고, 늦어도 24시간 뒤 자동 삭제됩니다.

## 6. 기술 구성

- 클라이언트 React + TypeScript, 서버 Cloudflare Workers + Durable Objects(방 하나 = 객체 하나, SQLite 저장소, WebSocket Hibernation). 서버가 방 상태의 유일한 기준이며 역할·라운드·입력을 서버에서 검증합니다.
- 이미지 36장은 OpenAI(ChatGPT) 이미지 생성으로, 음향 10개는 ElevenLabs로 제작했고 코드는 Claude Code로 작성했습니다. 세부 내역은 "06_AI활용내역_검증기록" 문서에 있습니다.
- 검증: 단위 테스트 19개, 학생 40명 동시 접속 시뮬레이션(세 분기), 극단적 선택 시나리오 21개, 운영 환경 재검증 통과. 실제 학급 수업 실증은 아직 하지 않았습니다.
