사용
PNG는 assets/images 안에 요청한 파일명으로 들어 있습니다.
문구, 이름, 숫자와 실제 게임 데이터는 앱의 HTML에서 표시하세요.
생성 파일은 이미지 후처리 없이 원본 PNG 그대로 제공합니다.
배지 2장은 투명 배경이며 다른 이미지는 배경 포함입니다.
실존 학생의 사진을 사용하지 않은 가상의 인물입니다.

앱 연결을 맡은 개발자에게
이 패키지는 이미지 자산입니다. 앱 코드 연결과 배포는 포함하지 않았습니다.
요청서가 안내한 후속 작업: 프로젝트의 이미지 변환 스크립트(npm run images) 실행 후
src/client/lib/images.ts의 PROVIDED 목록에 해당 ID 추가.
현재 프로젝트 구현과 기존 목록을 먼저 확인하고 적용하세요.
